Generate an image from a text prompt and attach it to the conversation. Provider-agnostic: tries the local FLUX image hub first (fast, no API key), falling back to Recraft or Gemini if their API keys are configured and the local hub is unavailable. Use this when the user asks you to create, draw, generate, or mock up an image, illustration, icon, or picture. Not for editing existing images or for diagrams best expressed as code/markup. If no image provider is available, the tool reports that clearly instead of failing silently.
