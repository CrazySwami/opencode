Inspect and operate the OpenCode workspace tab registry. Use this when the user asks what tabs exist, wants a tab opened/focused/closed, asks which tools belong to a tab, or wants a snapshot/action request for Browser, Terminal, Open Design, Mac View, Resources, Codex accounts, Artifacts, File Browser, Routines, or Environment. `panel://preview` is kept only as a compatibility alias and opens `panel://browser`.

This tool returns structured JSON. The OpenCode web client owns visible browser-local tab state, so open/focus/close/run_action return clientAction requests that the UI can execute or display. Use the underlying specialized tools for actual work: browser/browser_use for the unified Browser, terminal/bash for shell commands, open_design for Open Design daemon/API, mac_view for Mac feed/status, resource_status for resources, artifact for artifacts, file_browser for files, account_status for account state, and routines for scheduled jobs.
