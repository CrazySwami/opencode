Inspect and operate the OpenCode workspace tab registry. Use this when the user asks what tabs exist, wants a tab opened/focused/closed, asks which tools belong to a tab, or wants a snapshot/action request for Browser, Preview, Terminal, Open Design, Mac View, Resources, Codex accounts, Artifacts, File Browser, Routines, or Environment.

This tool returns structured JSON. The OpenCode web client owns visible browser-local tab state, so open/focus/close/run_action return clientAction requests that the UI can execute or display. Use Browser for public internet, login-heavy work, Browser Use, Playwright, selectors, console/network, and persistent Chrome profile tasks. Use Preview for controlled/internal/local URLs, OpenDesign, project previews, files, and lightweight form interaction where iframe or Chromium-rendered fallback is enough. Use the other specialized tools for actual work: terminal/bash for shell commands, open_design for Open Design daemon/API, mac_view for Mac feed/status, resource_status for resources, artifact for artifacts, file_browser for files, account_status for account state, and routines for scheduled jobs.
