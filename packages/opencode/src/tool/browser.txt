Operate the OpenCode Browser surface. Use this when the task needs a real interactive browser for public websites, local apps, hosted product previews, Open Design, forms, DOM snapshots, element highlighting, network/console inspection, or screenshots. The visible Browser tab is the shared Chrome/Chromium surface for Alfonso and model browser tools; older Preview requests are compatibility aliases that open Browser.

Each OpenCode session gets its own browser session name and persistent profile. Start with action=open for a new session, then use actions like goto, snapshot, click, click-point, type, press, scroll, fill, highlight, screenshot, requests, console, or tab-list. Screenshot results are attached back to the conversation when a PNG is produced.

The Browser tab's primary viewing/control path is Chrome DevTools Protocol (CDP); VNC/noVNC is only a fallback. The browser is still a real browser with network access. Avoid entering or exposing secrets unless the user explicitly authorizes it. The dedicated live Chrome profile can persist state; extensions and password managers remain separate explicit opt-ins.
