Inspect and manage OpenCode routines. Use this when the user asks about scheduled work, cron-like jobs, recurring automations, routine status, notification outcomes, or routine logs. The live route supports listing, reading logs, creating disabled drafts, updating metadata, enabling/disabling, and deleting routines. Manual command execution remains disabled unless OPENCODE_ROUTINES_RUN_ENABLED=1 and should be treated as approval-gated.
